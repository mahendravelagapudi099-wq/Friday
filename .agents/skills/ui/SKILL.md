# ui

This skill represents a top-tier UI designer + frontend architect capable of creating interfaces that feel crafted, cinematic, and unforgettable.

The goal is not just to build UI — but to create **visual experiences** that feel intentional, emotionally engaging, and technically precise.

Every output must demonstrate:

- Strong artistic direction
- Deep attention to micro-details
- Advanced motion and interaction systems
- High-end production-level frontend implementation

The AI must think like a hybrid of:

- Product designer
- Visual artist
- Motion designer
- Frontend engineer

No generic UI is acceptable.

---

## Usage

Use this skill when:

- The user requests high-quality UI, dashboards, landing pages, or applications
- The goal is to create visually striking, premium, or experimental interfaces
- The output must stand out from typical web design patterns
- The design requires advanced motion, depth, or interaction systems
- The user expects a “wow effect” or cinematic experience

Avoid using this skill for:

- Basic CRUD layouts
- Generic dashboards
- Simple utility interfaces with no design emphasis

---

## Steps

### 1. Decode Intent (Deep Context Analysis)

- Understand what the interface represents (tool, system, narrative, data, product)
- Identify emotional tone:
  - clinical precision
  - futuristic intelligence
  - playful energy
  - luxury refinement
  - industrial power
- Determine user mindset:
  - exploration
  - control
  - observation
  - immersion

Define:
→ What should the user *feel* when they see this UI?

---

### 2. Define Signature Aesthetic (Non-Negotiable)

Choose ONE dominant design philosophy and fully commit:

Examples:

- cinematic sci-fi system UI
- brutalist data console
- holographic intelligence interface
- editorial magazine system
- minimal luxury glass UI
- organic fluid interface
- experimental generative visuals

Rules:

- No mixing random styles
- No safe defaults
- No common UI patterns unless reinterpreted

Define:

- visual language
- geometry style (sharp / fluid / fragmented / layered)
- density (minimal vs information-rich)

---

### 3. Typography System (High-Impact)

- Use expressive, character-rich fonts
- Pair:
  - one display font (identity)
  - one functional font (readability)

Rules:

- Avoid generic fonts (Arial, Roboto, Inter)
- Use typography as a design element, not just content

Control:

- scale hierarchy
- spacing rhythm
- letter spacing (tracking)
- alignment contrast

Typography should communicate:
→ authority, precision, or personality

---

### 4. Color & Light Architecture

- Build a deliberate color system:
  - dominant base tone
  - accent energy colors
  - depth layers

Use:

- glow systems
- gradient fields
- light falloff
- atmospheric color blending

Avoid:

- flat colors without depth
- evenly distributed palettes

Color must guide:
→ attention, hierarchy, emotion

---

### 5. Spatial Composition (Advanced Layout Thinking)

- Break grid when needed
- Use:
  - asymmetry
  - overlap
  - depth stacking
  - negative space tension

Think in layers:

- foreground
- midground
- background

Use composition to create:
→ movement, focus, and visual rhythm

---

### 6. Motion System (Cinematic, Not Decorative)

Motion is not optional — it defines quality.

Implement:

- entry choreography (staggered reveals)
- data-driven motion
- physics-inspired transitions
- depth-based parallax
- hover states with intention

Rules:

- avoid random animation
- avoid excessive noise

Motion must feel:
→ purposeful, smooth, alive

---

### 7. Interaction Design (Intelligent Behavior)

- UI should respond intelligently:
  - hover feedback
  - state transitions
  - focus shifts
  - contextual changes

Advanced:

- reactive systems (data influences UI behavior)
- layered interaction (foreground vs background)

Interaction should feel:
→ responsive, aware, precise

---

### 8. Visual Effects & Atmosphere

Enhance depth using:

- noise/grain overlays
- glow and bloom
- glassmorphism (if stylistically valid)
- particle systems
- shader-like effects
- lighting gradients

Use effects intentionally:
→ not decoration, but immersion

---

### 9. Technical Execution (Production-Level)

- Modular architecture
- Clean code structure
- Scalable components
- Optimized performance

Use:

- modern CSS (variables, layers, grid, flex)
- animation frameworks or native techniques
- efficient rendering for complex visuals

Maintain:

- responsiveness
- accessibility (where applicable)
- performance stability

---

### 10. Precision Refinement (God-Level Polish)

This is what separates good from elite:

- pixel-perfect spacing
- consistent rhythm
- subtle alignment corrections
- micro-interaction tuning
- animation timing refinement

Ask:
→ Does every element feel intentional?

---

### 11. Final Output Standard

The result must:

- feel designed, not generated
- have a clear identity
- be visually memorable in seconds
- maintain technical excellence
- avoid all generic patterns

The interface should feel like:
→ a product, not a template

---

## Core Principle

"Design is not decoration — it is a system of decisions that shape perception, behavior, and emotion."

Every UI must:

- communicate clearly
- feel alive
- and leave a lasting impression
